RL · 강화학습 시연

Unity 강화학습으로 학습한 다른 버전

위 3D 시뮬레이션과는 별개로, Unity ML-Agents 플랫폼에서 강화학습(RL) 에이전트가 서울 10년치 기상 데이터를 하루씩 겪으며 태양 고도에 따라 음영을 피하고 발전량을 최대화하는 루버 각도를 스스로 찾아가도록 학습한 또 다른 버전입니다. 아래 영상은 학습이 끝난 정책이 실제 하루를 따라가며 루버를 제어하는 모습입니다.

05 · 어떻게 학습했나

10년의 기상 데이터에서, 발전소 한 동까지

기상청 10년 시계열로 1차 학습 → 시간순 홀드아웃 검증으로 정밀도 확인 → 향후 실제 발전소 데이터로 사이트 맞춤 fine-tune. 단계별 서사입니다.

STEP 1

1차 학습

서울 종로 관측소 기상청 ASOS 10년 (2014–2023), 시간 단위 44,225 행. 입력 피처는 시간(sin/cos) · 일자(sin/cos) · GHI · 운량 · 기온 총 7개. 출력은 물리 모델로 산출한 시간별 최적 루버 각도. 모델은 XGBoost 회귀.

STEP 2

검증

시간순 홀드아웃(마지막 20%)으로 모델 안정성 확인. R² = —, MAE = —° (주간 기준). 제어 모터 정밀도 ±2° 대비 충분히 정밀합니다.

STEP 3

향후 · 사이트 맞춤

실제 설치 발전소에서 패널별 발전량 데이터 수집, 주변 건물 · 나무가 만드는 사이트별 음영 패턴 학습, 모델 fine-tune으로 발전소 한 동마다 최적 모델로.
