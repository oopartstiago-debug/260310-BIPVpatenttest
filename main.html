V15 선분교차 (Ray–Blade Intersection). 이전 버전(V13~V14)이 음영을 코사인 근사로 추정하던 것과 달리, V15 는 실제 태양 광선의 경로를 추적해 발전면 위의 정확한 그림자 위치를 계산합니다. 발전면 = 블레이드의 바깥쪽 면 (피봇 → 바깥끝, 태양전지 부착면). 그림자는 피봇(안쪽)에서 바깥 방향으로 채워지며, 90° 수직이면 블레이드가 나란히 서서 서로의 발전면을 가리지 않아 SF = 0%.

05 · 어떻게 학습했나

10년의 기상 데이터에서, 발전소 한 동까지

기상청 10년 시계열로 1차 학습 → 5-fold 교차검증으로 정밀도 확인 → 향후 실제 발전소 데이터로 사이트 맞춤 fine-tune. 단계별 서사입니다.

STEP 1

1차 학습

서울 종로 관측소 기상청 ASOS 10년 (2014–2023), 시간 단위 44,225 행. 입력 피처는 시간(sin/cos) · 일자(sin/cos) · GHI · 운량 · 기온 총 7개. 출력은 물리 모델로 산출한 시간별 최적 루버 각도. 모델은 XGBoost 회귀.

STEP 2

검증

5-fold 교차검증으로 모델 안정성 확인. R² = 0.9966 (분산의 99.66 % 설명), MAE = 0.70° (평균 0.7° 이내). 제어 모터 정밀도 ±2° 대비 충분히 정밀합니다.

STEP 3

향후 · 사이트 맞춤

실제 설치 발전소에서 패널별 발전량 데이터 수집, 주변 건물 · 나무가 만드는 사이트별 음영 패턴 학습, 모델 fine-tune으로 발전소 한 동마다 최적 모델로.
