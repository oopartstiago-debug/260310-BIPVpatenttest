# env_check — 클린룸 독립 검증 환경

목적: physics_v3 계보(v15→v17)에서 결론이 3번 뒤집힌 이력(치수 placeholder·VF 현 2배·IAM/알베도 미모델)
→ "아직 모르는 설정 오류"를 잡기 위해 **코드 계보가 다른 독립 물리 환경**을 짓고 교차검증한다.

## 클린룸 규칙
1. `physics_v3.py` / `train_v17.py` / `app.py` 를 **임포트·참조하지 않는다** (P3 교차대조 하네스 제외).
2. 기하 입력은 도면 `blade_drawing_1043A.png` 판독값만:
   - 날개 간격(피치) **97.5mm** (도면 명기)
   - 닫힘 연속면(A-A 단면) → 현 = 피치 = **97.5mm**
   - PV 셀 띠 **83mm 중앙 배치** (마진 7.25mm×2), 피벗 = 현 중앙
   - 프레임 깊이 **100mm**
3. 알고리즘을 기존과 다르게: 음영=shapely 다각형 투영(↔해석적 선분교차),
   확산광=각도 광선캐스팅(↔MC 시야계수 테이블), 태양위치=pvlib 직접 호출.
4. 정직한 한계: 두 엔진의 저자가 같음 → 완전한 독립은 아님.
   보완 = 알고리즘 차별화 + **사용자 육안 게이트**(렌더 vs 도면) + 불일치 전수 보고.

## 페이즈
- **P1** 기하 엔진(`geometry.py`) + 정지 렌더(`render_static.py`) → `out/p1_scenes.png` — 게이트: 사용자 육안
- **P2** 독립 조도·발전 엔진 (pvlib + 광선캐스팅 확산 + Martin-Ruiz IAM + 알베도)
- **P3** 전수 교차대조 vs physics_v3 (시간별 최적각·연간 사다리) → 일치/불일치 보고서
- **P4** pygame 실시간 시뮬레이터 (하루 애니메이션, 수동/oracle 모드)
- **P5** (선택) gymnasium 래퍼

## 좌표/각도 규약
- 단면 2D: 가로축 y = 파사드 바깥(남쪽) 방향 +, 세로축 z = 상방 +. 피벗 y=0.
- tilt 0° = 수평 개방, 90° = 수직 완전닫힘 (v17 라벨과 동일 규약).
- 빔 음영은 프로파일각(profile angle): tan β = tan(고도) / cos(태양방위 − 파사드방위).

실행: 프로젝트 `.venv/bin/python` (conda 아님).
